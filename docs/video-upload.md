## Title

QuietBridge — Privacy Delivery for Alexa+ Shared Spaces

## Description

QuietBridge is a context-aware privacy delivery layer for assistants used in shared spaces. This
working-product demo shows a real MCP Streamable HTTP server classifying protected fields, keeping
sensitive appointment details out of public speech, creating a profile-bound one-time private
handoff, denying the wrong profile, producing a content-free privacy receipt, reporting deletion
honestly, and failing closed when identity is unknown.

The Alexa, identity, phone, and calendar surfaces are clearly labelled test adapters. The MCP
server, five tools, privacy policy, signed authentication boundary, expiring handoffs, receipts,
deletion, encrypted local persistence option, security controls, and automated tests are real.

Source: https://github.com/dlc04022006-stack/quietbridge

Built for the Build, Ship, Shape: Amazon Developer Hackathon — Alexa+ and Open Source tracks.
